# Quickstart: Modern Web Guidance

1. Activate the configuration with `nh os switch .`.
2. Start Codex or OpenCode and ask it to implement a web UI or client-side JavaScript change.
3. The agent loads `modern-web-guidance` and follows its upstream instructions to decide whether and how to invoke the Modern Web Guidance CLI.
4. For project-specific skills, continue using the Vercel Skills CLI provided by the shared development tools.
